# Contributing to Digital Guardians

Thank you for your interest in contributing to Digital Guardians! This project aims to create a safer digital environment for families in Singapore, and we welcome contributions from everyone.

## How You Can Contribute

### 1. Content Contributions
- **Educational Materials**: Share lesson plans, activities, or educational resources
- **Translations**: Help translate content into Singapore's official languages
- **Case Studies**: Submit success stories or real-world examples
- **Best Practices**: Contribute digital safety tips and guidelines

### 2. Technical Contributions
- **Documentation**: Improve or expand existing documentation
- **Templates**: Create helpful templates for parents and educators
- **Tools**: Develop interactive tools or resources
- **Accessibility**: Help make resources more accessible

### 3. Community Contributions
- **Ambassador Program**: Join as a community ambassador
- **Workshops**: Conduct or organize digital safety workshops
- **Feedback**: Provide feedback on existing resources
- **Testing**: Test new materials with your community

## Contribution Guidelines

### Content Standards
1. **Age-Appropriate**: Ensure content is suitable for the intended audience
2. **Accurate**: Verify all technical information is current and correct
3. **Inclusive**: Use inclusive language and consider diverse perspectives
4. **Actionable**: Provide practical, actionable advice
5. **Singapore-Focused**: Consider Singapore's context and culture

### Quality Checklist
- [ ] Content is clear and easy to understand
- [ ] Grammar and spelling are correct
- [ ] Sources are cited where applicable
- [ ] Content is original or properly attributed
- [ ] Sensitive topics are handled appropriately
- [ ] Content aligns with project values

### Submitting Content

#### For GitHub Users
1. Fork the repository
2. Create a new branch (`git checkout -b feature/your-contribution`)
3. Add your content following the project structure
4. Commit your changes with clear messages
5. Push to your branch
6. Submit a Pull Request with a detailed description

#### For Non-GitHub Users
1. Email your contribution to: digitalguardians@singapore.gov.sg
2. Include:
   - Your name and affiliation (optional)
   - Description of your contribution
   - Target audience
   - Any supporting materials or references

### Translation Guidelines

When translating content:
1. Maintain the original meaning and tone
2. Adapt examples to be culturally relevant
3. Use formal/informal language appropriately
4. Include translator notes for context-specific terms
5. Follow naming convention: `[filename]-[language-code].md`
   - Example: `online-safety-basics-zh.md` (Chinese)
   - Example: `online-safety-basics-ms.md` (Malay)
   - Example: `online-safety-basics-ta.md` (Tamil)

### Code of Conduct

All contributors must adhere to our Code of Conduct:
- Be respectful and considerate
- Welcome diverse perspectives
- Provide constructive feedback
- Focus on what's best for the community
- Maintain confidentiality when handling sensitive information

### Review Process

1. **Initial Review** (1-3 days)
   - Maintainers review for alignment with project goals
   - Check for completeness and quality

2. **Community Feedback** (3-7 days)
   - Community members may provide input
   - Suggestions for improvements

3. **Final Review** (1-2 days)
   - Final approval by project maintainers
   - Merge into main repository

### Recognition

Contributors will be recognized in the following ways:
- Listed in project acknowledgments
- Certificate of contribution (for significant contributions)
- Featured in community newsletters
- Opportunity to become a project maintainer

## Legal Considerations

By contributing to Digital Guardians, you agree that:
1. Your contribution is your original work or you have rights to share it
2. You grant Digital Guardians the right to use your contribution
3. Your contribution adheres to the MIT License
4. You will not include sensitive personal information without consent
