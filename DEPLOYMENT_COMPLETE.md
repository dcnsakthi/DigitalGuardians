## How to Deploy

### Method 1: Repository Settings (Recommended)
1. Go to repository **Settings**
2. Navigate to **Pages** (in left sidebar)
3. Under "Source", select your branch
4. Click **Save**
5. Site will be live at: `https://dcnsakthi.github.io/DigitalGuardians/`

### Method 2: GitHub Actions (Automatic)
- Already configured in `.github/workflows/pages.yml`
- Automatically deploys when changes are pushed to `main`
- No manual intervention needed
