Introduction

Our devices contain sensitive personal information, financial data, photos, and communications. Securing them properly is essential to protecting your family's privacy and safety. This guide provides practical steps to secure all your family's devices.

  • Network security at home

Computer Security (Windows & Mac)

Essential Security Settings

Windows 10/11 Security Checklist

  • Enable Windows Defender/Microsoft Defender
  • Turn on Windows Firewall
  • Enable automatic Windows Updates
  • Create separate user accounts for each family member
  • Use strong passwords or PINs for all accounts
  • Enable BitLocker encryption (on supported systems)
  • Turn on Find My Device feature
  • Set screen lock after 5 minutes of inactivity
  • Disable unused services and features
  • Review app permissions regularly

macOS Security Checklist

  • Keep macOS updated to latest version
  • Enable FileVault disk encryption
  • Turn on Firewall in System Preferences → Security & Privacy
  • Use strong passwords for user accounts
  • Enable Find My Mac
  • Turn on automatic app updates
  • Only download apps from App Store or trusted sources
  • Enable screen lock with password
  • Review Security & Privacy settings regularly
  • Use Touch ID or Apple Watch for authentication when available

User Account Management

Account Type Use For Permissions
Administrator Parents only Can install software, change settings
Standard User Children, teens Limited system changes, needs admin approval for installations
Guest Visitors No permanent changes, no access to files

💡 Pro Tip: Don't Use Admin Account Daily

Even parents should use a standard user account for daily activities and only switch to administrator when needed. This limits damage from malware infections.

Mobile Device Security

iOS (iPhone/iPad) Security

Essential Settings

  • Settings → Face ID/Touch ID & Passcode → Set strong passcode (6+ digits)
  • Settings → Privacy → Review all app permissions
  • Settings → Apple ID → Find My → Enable Find My iPhone
  • Settings → Screen Time → Set app limits and downtime
  • Settings → General → Software Update → Enable automatic updates
  • Settings → Cellular → Review which apps can use cellular data
  • Settings → Privacy → Location Services → Set to "While Using App" for most apps
  • Settings → App Store → Require password for purchases
  • Only download apps from official App Store
  • Enable two-factor authentication for Apple ID

For Children's Devices

  • Use Family Sharing with parental controls
  • Enable Ask to Buy for app purchases
  • Set Screen Time limits with specific app restrictions
  • Restrict adult content and explicit content
  • Disable in-app purchases or require password
  • Review Communication Limits

Android Security

Essential Settings

  • Settings → Security → Screen lock → Set PIN, pattern, or password
  • Settings → Security → Find My Device → Enable
  • Settings → System → System update → Enable automatic updates
  • Settings → Apps → Permissions → Review all app permissions
  • Settings → Location → Set app location permissions carefully
  • Settings → Google → Security → Turn on 2-Step Verification
  • Settings → Google → Ads → Opt out of personalization
  • Only download apps from Google Play Store
  • Settings → Security → Play Protect → Keep enabled
  • Disable "Install unknown apps" for all sources

For Children's Devices

  • Set up Family Link for parental controls
  • Approve all app downloads and purchases
  • Set screen time limits
  • Filter inappropriate content
  • Monitor app usage and activity
  • Set device bedtime hours

App Permissions Management

Understanding Permissions

Apps request permissions to access device features. Review these carefully:

Permission Why Apps Need It When to Allow
Camera Take photos/videos Photo apps, video calls, social media
Microphone Record audio Voice calls, voice assistants, recording apps
Location GPS tracking, local services Maps, weather, delivery apps (only while using)
Contacts Access phone numbers Messaging apps, social media (with caution)
Photos Access stored images Photo editing, social media, cloud backup
Storage Save files Most apps that create or store data

Permission Best Practices

  • Principle of least privilege: Only grant permissions that are necessary
  • Review regularly: Check permissions monthly
  • Location: "While Using": Prefer this over "Always"
  • Question unnecessary requests: Why does a flashlight app need your contacts?
  • Revoke unused permissions: Remove permissions from apps you rarely use

⚠️ Red Flags

Be suspicious of apps that request permissions unrelated to their function (e.g., a calculator wanting your contacts and location). This could indicate malware or data harvesting.

Malware Protection

What is Malware?

Malware (malicious software) includes viruses, trojans, spyware, ransomware, and adware designed to harm your device or steal data.

Protection Strategies

For Windows

  • Use Windows Defender (built-in, free, and effective)
  • Keep Windows and all software updated
  • Only download from official sources
  • Be cautious with email attachments
  • Don't click suspicious links
  • Use standard user account for daily use
  • Enable controlled folder access (ransomware protection)

For Mac

  • macOS has built-in security (XProtect, Gatekeeper)
  • Keep macOS updated
  • Only install apps from App Store or identified developers
  • Don't disable Gatekeeper unless absolutely necessary
  • Be cautious with downloads
  • Consider third-party antivirus for extra protection (optional)

For Mobile Devices

  • iOS: Generally secure, but keep updated and only use App Store
  • Android: Keep Play Protect enabled, update regularly
  • Don't jailbreak/root devices (removes security protections)
  • Review app permissions carefully
  • Uninstall apps you don't use

Signs of Malware Infection

  • Device running slowly or overheating
  • Unexpected pop-ups or ads
  • Apps crashing frequently
  • Battery draining quickly
  • Unknown apps installed
  • Unusual network activity
  • Browser redirects to strange websites
  • Contacts receiving spam from your accounts

If You Suspect Malware

  1. Disconnect from internet
  2. Run full antivirus scan
  3. Remove any suspicious apps
  4. Change important passwords from clean device
  5. Check for unauthorized charges/purchases
  6. Consider professional help for serious infections
  7. Factory reset as last resort (backup important data first)

Backup and Recovery

The 3-2-1 Backup Rule

  • 3 copies of your data (original + 2 backups)
  • 2 different media types (external drive, cloud, etc.)
  • 1 copy off-site (cloud or physical location away from home)

Windows Backup

  • Enable File History for automatic backups
  • Use OneDrive for cloud backup of important files
  • Create system image periodically
  • Test restore process to ensure backups work

Mac Backup

  • Enable Time Machine with external drive
  • Use iCloud for documents and photos
  • Consider additional cloud backup (Backblaze, CrashPlan)
  • Test restoring files periodically

Mobile Backup

  • iOS: Enable iCloud Backup (Settings → Apple ID → iCloud → iCloud Backup)
  • Android: Enable Google Drive backup (Settings → Google → Backup)
  • Back up photos to cloud service
  • Export important contacts and data

💡 Automate Your Backups

Set up automatic backups so you don't have to remember. Manual backups often don't happen when you need them most.

Home Network Security

Router Security Checklist

  • Change default admin username and password
  • Update router firmware regularly
  • Use WPA3 or WPA2 encryption (not WEP)
  • Create strong WiFi password (16+ characters)
  • Change default network name (SSID)
  • Disable WPS (WiFi Protected Setup)
  • Enable router firewall
  • Disable remote management unless needed
  • Create guest network for visitors
  • Review connected devices regularly

WiFi Best Practices

  • Home network: Use strong password, enable encryption
  • Public WiFi: Use VPN, avoid sensitive transactions
  • Guest network: Isolate visitors from main network
  • IoT devices: Put smart devices on separate network if possible

Using VPN (Virtual Private Network)

When to use VPN:

  • On public WiFi networks
  • When traveling
  • For additional privacy at home
  • To access region-restricted content safely

Choosing a VPN:

  • Research reputation and privacy policy
  • Avoid free VPNs (often sell your data)
  • Look for no-logs policy
  • Consider: NordVPN, ExpressVPN, ProtonVPN

Physical Security

Protecting Physical Access

  • Always lock devices when leaving them
  • Don't leave devices unattended in public
  • Use privacy screens in public places
  • Be aware of shoulder surfers
  • Store devices securely at home
  • Use cable locks for laptops in public spaces

Lost or Stolen Device Protocol

Immediate Actions

  1. Use Find My Device feature to locate
  2. Lock device remotely
  3. Display contact message on lock screen
  4. Change passwords from another device
  5. Contact your carrier to suspend service
  6. Report to police if stolen
  7. Erase device remotely if recovery unlikely

Prevention

  • Enable Find My Device before loss occurs
  • Write down device serial numbers
  • Consider device insurance
  • Use lock screen with password/biometric
  • Don't store passwords in plain text

Smart Device Security (IoT)

Securing Smart Home Devices

  • Change default passwords immediately
  • Keep firmware updated
  • Use separate network for IoT devices
  • Disable unnecessary features
  • Review privacy settings
  • Research security before buying
  • Only buy from reputable manufacturers

Common Smart Devices to Secure

  • Smart speakers (Alexa, Google Home)
  • Security cameras
  • Smart TVs
  • Smart thermostats
  • Smart locks
  • Baby monitors
  • Smart appliances

Device Security Schedule

Weekly Tasks

  • Review recent account activity for anomalies
  • Update apps that require manual updates
  • Clear browser cache and cookies

Monthly Tasks

  • Review app permissions on mobile devices
  • Check for operating system updates
  • Review connected devices on network
  • Test backups by restoring a file
  • Clear unnecessary files and apps

Quarterly Tasks

  • Change important passwords
  • Review security settings on all devices
  • Update router firmware
  • Audit installed apps and remove unused ones
  • Review privacy settings on online accounts

Annually Tasks

  • Complete security assessment of all devices
  • Review and update family technology rules
  • Research new security threats
  • Consider hardware upgrades for old devices
  • Properly dispose of old devices (wipe data first)
