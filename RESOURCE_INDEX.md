## 🎯 Get Started Based on Your Need

### "I'm a parent new to digital safety"
1. Start with [Parent Guide](docs/parents/README.md)
2. Review [Age Guidelines](docs/parents/age-guidelines.md) for your child's age
3. Use [Conversation Starters](docs/parents/conversation-starters.md)
4. Create a [Family Agreement](docs/parents/family-agreement-template.md)

### "I'm a teacher planning lessons"
1. Read [Educator Resources](docs/educators/README.md)
2. Try our [Sample Lesson Plan](docs/educators/lesson-plans/think-before-you-post.md)
3. Adapt materials for your class
4. Join the [Educator Community](docs/community/README.md)

### "I want to help my community"
1. Learn about [Ambassador Program](docs/ambassadors/README.md)
2. Review training requirements
3. Apply to become an ambassador
4. Connect with [Community Network](docs/community/README.md)

### "I'm a young person seeking help"
1. Read [Online Safety Basics](docs/youth/online-safety-basics.md)
2. Use [Safety Checklist](resources/templates/safety-checklist.md)
3. Know [Emergency Contacts](docs/youth/online-safety-basics.md#need-help)
4. Talk to trusted adult

### "I need immediate help"
- **Police Emergency**: 999
- **TOUCH Cyber Wellness**: 1800-377-2252
- **Tinkle Friend**: 1800-274-4788
- See full list in [Best Practices](docs/best-practices/README.md#emergency-response)
