# Digital Safety Quick Reference Checklist

Print this checklist and keep it near your computer or device as a quick reminder of digital safety best practices.

---

## 📱 Daily Digital Safety Habits

### Before You Post or Share
- [ ] Is this true and accurate?
- [ ] Would I be okay if everyone saw this?
- [ ] Am I sharing personal information?
- [ ] Could this hurt someone's feelings?
- [ ] Will I be proud of this in 5 years?

### When Browsing Online
- [ ] Check for "https://" and padlock icon
- [ ] Avoid clicking suspicious links
- [ ] Don't download from untrusted sources
- [ ] Use privacy/incognito mode when needed
- [ ] Clear browser history regularly

### When Messaging
- [ ] Only communicate with people I know
- [ ] Think before sending
- [ ] Don't share personal information
- [ ] Block and report suspicious contacts
- [ ] Tell parent/trusted adult if uncomfortable

---

## 🔒 Account Security Essentials

### Password Checklist
- [ ] At least 12 characters long
- [ ] Mix of upper and lowercase letters
- [ ] Includes numbers and symbols
- [ ] Unique for each account
- [ ] Not based on personal information
- [ ] Changed regularly (every 3-6 months)
- [ ] Never shared (except with parents)

### Account Protection
- [ ] Two-factor authentication enabled
- [ ] Recovery email/phone number updated
- [ ] Security questions are not easily guessable
- [ ] Regular login activity review
- [ ] Log out on shared devices
- [ ] Use password manager

---

## 🛡️ Privacy Settings Review

### Monthly Privacy Check
- [ ] Review who can see your posts
- [ ] Check who can see your photos
- [ ] Verify friend/follower list
- [ ] Update location sharing settings
- [ ] Review third-party app permissions
- [ ] Check tagging settings
- [ ] Disable public search indexing

### Social Media Specific
- [ ] Account set to private/friends only
- [ ] Profile information minimal
- [ ] Location services turned off
- [ ] Activity status hidden
- [ ] Story/post visibility controlled

---

## 🚫 Never Share Online

### Personal Information (RED ZONE)
- [ ] Full name, address, phone number
- [ ] School name and location
- [ ] Parents' information
- [ ] Social Security/ID numbers
- [ ] Passwords
- [ ] Financial information
- [ ] Travel plans (in real-time)
- [ ] Daily routines and schedules

### Visual Information
- [ ] Photos showing house number
- [ ] Images with car license plates
- [ ] School uniforms with visible badges
- [ ] Location-tagged photos (real-time)
- [ ] Compromising or inappropriate images

---

## ⚠️ Warning Signs of Danger

### Suspicious Online Behavior
- [ ] Someone asks for personal information
- [ ] Requests to keep conversation secret
- [ ] Asked to send photos/videos
- [ ] Pressure to meet in person
- [ ] Offers of gifts or money
- [ ] Asked to do uncomfortable things
- [ ] Age or identity seems fake
- [ ] Becomes angry if you don't respond quickly

### Scam Red Flags
- [ ] Too good to be true offers
- [ ] Urgent action required
- [ ] Requests for money or payment info
- [ ] Spelling and grammar errors
- [ ] Suspicious sender address
- [ ] Asks for passwords
- [ ] Threatens account closure

## 💻 Device Security Basics

### Phone/Tablet
- [ ] Strong passcode or biometric lock
- [ ] Auto-lock enabled (30-60 seconds)
- [ ] Find My Device activated
- [ ] Automatic updates turned on
- [ ] Only apps from official stores
- [ ] Regular review of app permissions
- [ ] Encryption enabled
- [ ] Backup created regularly

### Computer
- [ ] Antivirus software installed
- [ ] Firewall enabled
- [ ] Operating system updated
- [ ] Browser updated
- [ ] Screen lock with password
- [ ] Auto-lock after inactivity
- [ ] Secure Wi-Fi connection
- [ ] Regular backups

## 📧 Email Safety

### Before Opening Email
- [ ] Verify sender is legitimate
- [ ] Check for spelling errors
- [ ] Don't open suspicious attachments
- [ ] Hover over links (don't click yet)
- [ ] Look for urgency as red flag

### Email Best Practices
- [ ] Use spam filters
- [ ] Never share password via email
- [ ] Be careful what you write
- [ ] Verify recipients before sending
- [ ] Use BCC for mass emails
- [ ] Report phishing attempts

---

## 🎮 Gaming Safety

### Online Gaming Checklist
- [ ] Use privacy settings
- [ ] Don't share personal info in chat
- [ ] Play on official servers
- [ ] Report toxic players
- [ ] Don't click links in chat
- [ ] Be skeptical of "free items" offers
- [ ] Get parent permission for purchases

- [ ] Avoid sensitive transactions (banking)
- [ ] Use VPN if available
- [ ] Ensure websites use https://
- [ ] Turn off automatic Wi-Fi connection
- [ ] Forget network after use
- [ ] Use mobile data for sensitive activities

## 👥 Social Media Safety

### Before Accepting Friend/Follow Requests
- [ ] Do I know this person in real life?
- [ ] Is this a real account (check for verification)?
- [ ] Does the profile look suspicious?
- [ ] Have they messaged me appropriately?
- [ ] Are mutual friends legitimate?

### Posting Guidelines
- [ ] Apply T.H.I.N.K. framework
- [ ] Check privacy settings
- [ ] Remove location data from photos
- [ ] Ask permission before tagging others
- [ ] Think about future consequences
- [ ] Keep some things private

## 🎯 Quick Response Guide

### If You're Being Cyberbullied
1. Don't respond or retaliate
2. Take screenshots (evidence)
3. Block the person
4. Report to platform
5. Tell trusted adult
6. Keep evidence, don't delete

### If You Encounter Inappropriate Content
1. Close it immediately
2. Don't share or forward
3. Tell trusted adult
4. Report to platform
5. Clear from recent history

### If You Made a Mistake
1. Tell parent/trusted adult right away
2. Delete content if possible
3. Document what happened
4. Learn from it
5. Ask for help to prevent future issues

### If Someone Asks to Meet
1. Say NO
2. Don't delete messages (evidence)
3. Block the person immediately
4. Tell parent/trusted adult
5. Report to platform and possibly police

## 📋 T.H.I.N.K. Before You Post

Before sharing anything online, ask:

**T** - Is it **TRUE**?  
**H** - Is it **HELPFUL**?  
**I** - Is it **INSPIRING**?  
**N** - Is it **NECESSARY**?  
**K** - Is it **KIND**?

If you can't answer YES to all five, don't post it!
