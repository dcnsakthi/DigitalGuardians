## Community Guidelines

### Creating a Safe Space

**Be Respectful:**
- Treat others with kindness
- Value diverse perspectives
- Use inclusive language
- Avoid judgment

**Be Supportive:**
- Offer encouragement
- Share constructively
- Celebrate others' progress
- Help when you can

**Be Responsible:**
- Protect privacy (don't share others' information)
- Fact-check before sharing
- Report concerns appropriately
- Follow community guidelines

**Be Safe:**
- Don't share personal information publicly
- Report suspicious activity
- Protect children's privacy
- Use appropriate content only

### Reporting Issues

**If You See Something Concerning:**
1. Don't engage with the content
2. Take screenshots if needed
3. Report to moderators: report@digitalguardians.sg
4. Block users if necessary
5. Contact authorities if serious

**Community Moderation:**
- Trained volunteer moderators
- 24-48 hour response time
- Appeals process available
- Zero tolerance for abuse
