## Translation Guidelines

### For Contributors

When translating content:

1. **Maintain Accuracy**
   - Preserve the original meaning
   - Technical terms should be consistent
   - Don't add or remove information

2. **Cultural Adaptation**
   - Use culturally appropriate examples
   - Consider local context and norms
   - Adapt scenarios to be relevant

3. **Language Style**
   - Match formality level of original
   - Use clear, accessible language
   - Avoid overly technical jargon

4. **Technical Terms**
   - Use accepted translations for tech terms
   - Include English terms in parentheses when helpful
   - Be consistent across documents

5. **Quality Assurance**
   - Have translations reviewed by native speakers
   - Test materials with target audience
   - Update regularly to match English versions

## Singapore's Multilingual Context

Singapore's unique multilingual landscape means:
- Resources should be available in all official languages
- Visual materials are especially valuable (transcend language barriers)
- Community ambassadors should reflect linguistic diversity
- Materials should respect cultural differences

### Cultural Considerations

**Chinese Community:**
- Family hierarchy and respect for elders
- Value placed on education
- Concerns about academic impact of technology

**Malay Community:**
- Strong community and family ties
- Religious considerations (Islamic values)
- Emphasis on respect and courtesy

**Indian/Tamil Community:**
- Multi-generational households common
- Value on education and achievement
- Diverse religious and cultural practices

**All Communities:**
- Importance of academic success
- Respect for authority
- Collective responsibility
- Strong emphasis on family
