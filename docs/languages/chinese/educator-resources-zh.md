# 教育工作者数字安全资源

欢迎教育工作者！本指南为您提供全面的资源和工具，以在课堂和学校社区中教授数字安全。

## 概述

作为教育工作者，您在塑造学生的数字公民和安全实践方面发挥着至关重要的作用。本资源包提供了课程计划、活动和材料，以使数字安全教育既引人入胜又有效。

## 为什么数字安全教育很重要

### 对学生的影响
- 保护他们免受在线伤害
- 培养批判性思维技能
- 促进积极的数字公民意识
- 为未来的数字素养做准备
- 建立安全的在线习惯

### 对学校的好处
- 减少网络欺凌事件
- 提高学生幸福感
- 支持积极的学校文化
- 满足课程要求
- 让父母参与

## 按年级水平划分的课程计划

### 小学（7-9岁）

#### 课程1：什么是个人信息？
**学习目标：**
- 识别个人信息
- 理解为什么保密很重要
- 学习何时分享是安全的

**活动：**
1. **分类游戏** - 将信息分类为"可以分享"和"保持私密"
2. **角色扮演** - 练习说"不"的场景
3. **创建海报** - "保持私密的东西"

**时长：**40分钟

**材料：**
- 信息卡片
- 海报材料
- 工作表

#### 课程2：在线友善
**学习目标：**
- 理解数字礼仪
- 认识网络欺凌
- 练习友善的沟通

**活动：**
1. **故事时间** - 阅读关于在线友善的书
2. **讨论** - 友善的话语与刻薄的话语
3. **创意写作** - 写友善的在线消息

**时长：**45分钟

#### 课程3：我们的数字足迹
**学习目标：**
- 理解数字足迹
- 学习在线内容持续存在
- 发布前练习思考

**活动：**
1. **足迹艺术** - 创建物理足迹以可视化概念
2. **故事** - "永远的互联网"
3. **决策树** - 在发布前应该问什么？

**时长：**40分钟

### 初中（10-12岁）

#### 课程1：社交媒体安全
**学习目标：**
- 理解社交媒体平台
- 学习隐私设置
- 认识危险

**活动：**
1. **平台探索** - 研究热门应用
2. **隐私设置实践** - 动手活动
3. **场景分析** - 评估真实情况

**时长：**60分钟

**材料：**
- 设备访问
- 工作表
- 场景卡

#### 课程2：识别和应对网络欺凌
**学习目标：**
- 定义网络欺凌
- 认识警告信号
- 学习应对策略

**活动：**
1. **案例研究** - 分析网络欺凌场景
2. **角色扮演** - 练习回应
3. **行动计划** - 创建应对计划

**时长：**60分钟

#### 课程3：批判性思维与假新闻
**学习目标：**
- 识别错误信息
- 学习事实核查技巧
- 评估在线来源

**活动：**
1. **假或真实游戏** - 评估新闻故事
2. **来源评估** - 检查网站可信度
3. **创建清单** - 评估信息的步骤

**时长：**60分钟

### 高中（13-15岁）

#### 课程1：数字声誉与您的未来
**学习目标：**
- 理解数字足迹的长期影响
- 学习管理在线存在
- 为专业的未来做准备

**活动：**
1. **数字审计** - 搜索自己在线
2. **案例研究** - 真实的声誉影响
3. **行动计划** - 改进数字存在

**时长：**60-75分钟

#### 课程2：隐私、数据与权利
**学习目标：**
- 理解数据收集
- 学习隐私权利
- 掌握保护策略

**活动：**
1. **数据跟踪可视化** - 映射数据流
2. **政策审查** - 阅读并讨论隐私政策
3. **辩论** - 隐私与便利

**时长：**75分钟

#### 课程3：在线安全与人际关系
**学习目标：**
- 认识在线掠夺行为
- 理解健康关系
- 学习报告程序

**活动：**
1. **警告信号识别** - 识别危险行为
2. **资源映射** - 知道去哪里寻求帮助
3. **同伴教育** - 创建信息活动

**时长：**75分钟

## 互动活动

### 数字逃生室
**目标：**通过解决数字安全难题逃脱

**如何玩：**
1. 将班级分成小组
2. 提供场景和线索
3. 解决安全挑战以"逃脱"
4. 汇报所学内容

**时长：**45-60分钟

### 网络钓鱼识别游戏
**目标：**识别合法邮件与钓鱼尝试

**如何玩：**
1. 展示邮件示例
2. 学生投票：真实或网络钓鱼
3. 讨论线索
4. 评分正确识别

**时长：**30分钟

### 社交媒体模拟
**目标：**在安全环境中实践社交媒体决策

**如何运行：**
1. 创建虚拟社交媒体场景
2. 学生做出发布/分享决策
3. 讨论后果
4. 反思选择

**时长：**60分钟

### 密码强度比赛
**目标：**学习创建强密码

**如何玩：**
1. 介绍密码最佳实践
2. 学生创建密码
3. 使用工具测试强度
4. 分享策略

**时长：**30分钟

## 处理敏感问题

### 披露协议
如果学生披露伤害：
1. 保持冷静和支持
2. 倾听不带评判
3. 向适当的人员报告
4. 遵循学校政策
5. 记录详细信息

### 话题指南
- **网络欺凌** - 创造安全的讨论空间
- **不当内容** - 使用适合年龄的语言
- **在线掠夺** - 专注于识别和报告
- **心理健康** - 强调支持资源

### 敏感性提示
- 了解您的学生群体
- 尊重文化差异
- 提供选择退出选项
- 提供后续支持

## 紧急响应

### 网络欺凌事件
1. 立即干预
2. 记录证据
3. 支持受害者
4. 遵循学校协议
5. 通知家长
6. 必要时报告

### 不当内容
1. 隔离设备
2. 不要删除证据
3. 报告管理人员
4. 遵循法律要求
5. 支持学生

### 安全问题
1. 评估立即危险
2. 联系当局
3. 通知家长
4. 记录一切
5. 提供支持服务
