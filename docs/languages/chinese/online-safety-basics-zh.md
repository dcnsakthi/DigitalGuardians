# 青少年在线安全基础知识

欢迎！本指南专为您准备 - 帮助您保持安全、享受乐趣并充分利用在线时间。

## 为什么这很重要

您是真正在数字环境中成长的第一代。互联网是一个很棒的学习、创作、与朋友联系和表达自我的工具。但就像在现实世界中一样，在线也有一些风险。好消息是什么？您可以学会应对这些风险并在线保持安全！

## 互联网安全的黄金法则

### 🔒 法则1：保护您的个人信息
**什么是个人信息？**
- 您的全名、地址、电话号码
- 您的学校名称和位置
- 您父母的信息
- 您的密码
- 显示您住处的照片
- 您的确切位置
- 您的生日和年龄
- 您的日程和例行活动

**为什么重要：**
- 陌生人可以使用这些信息找到您
- 诈骗者可以用它来欺骗您或您的家人
- 它可能会让您陷入危险

**该怎么做：**
✅ 在分享个人信息之前询问父母
✅ 在所有账户上使用隐私设置
✅ 思考："我会把这些信息给街上的陌生人吗？" 如果不会，就不要在线分享
✅ 使用不包含真实姓名的用户名

### 🤝 法则2：对在线朋友保持警惕

**记住：**
- 不是每个在线的人都是他们所说的那个人
- 一些成年人假装是孩子来欺骗您
- 真正的朋友会尊重您的界限

**可能不安全的人的警告信号：**
🚩 他们要求您对你们的友谊保密
🚩 他们想知道关于您的个人详细信息
🚩 他们要照片或视频
🚩 他们想亲自见您
🚩 他们要求您做让您不舒服的事情
🚩 他们送您礼物或钱
🚩 如果您不立即回复，他们会生气
🚩 他们要求您不要告诉您的父母

**该怎么做：**
✅ 只接受您在现实生活中认识的人的好友请求
✅ 如果有人让您感到不舒服，告诉父母或信任的成年人
✅ 屏蔽并举报可疑账户
✅ 未经父母同意，绝不同意见您只在网上认识的人

### 💬 法则3：发布前要三思

**记住：互联网是永远的**
- 截图可以保存您发布的任何内容
- 已删除的帖子可能仍然存在于某处
- 未来的雇主、老师或学校可能会看到它
- 它可能会影响您多年的声誉

**在发布之前，问自己：**
1. 如果我的父母/老师看到这个，我会没事吗？
2. 这会伤害某人的感情吗？
3. 我分享了太多个人信息吗？
4. 5年后我会为此感到自豪吗？
5. 这是真实准确的吗？

**如果对任何问题的答案是"否"，就不要发布。**

### 🛡️ 法则4：使用强密码

**什么是强密码？**
✅ 至少8-12个字符长
✅ 大小写字母混合
✅ 包括数字
✅ 包括符号（!@#$%^&*）
✅ 与您的个人信息无关
✅ 每个账户都不同

**密码禁忌：**
❌ 不要使用您的姓名、生日或宠物的名字
❌ 不要使用"password"或"12345678"
❌ 不要与朋友分享密码（父母除外）
❌ 不要把密码写在别人能看到的地方

**专业提示：**使用密码短语！例如："我爱打篮球2024!" 既强大又容易记住。

### 👀 法则5：注意隐私

**检查您的隐私设置：**
- 谁可以看到您的帖子？
- 谁可以看到您的照片？
- 谁可以在搜索中找到您？
- 谁可以看到您的位置？
- 谁可以看到您的好友列表？
- 谁可以给您发消息？

**在每个平台上：**
✅ 将账户设为私密
✅ 只与您认识的人分享
✅ 关闭位置服务
✅ 定期审查设置

### 💪 法则6：对网络欺凌说不

**什么是网络欺凌？**
使用技术来：
- 发送刻薄或威胁性的消息
- 传播关于某人的谣言
- 分享尴尬的照片或视频
- 故意排除某人
- 假装是别人
- 发布刻薄的评论

**如果您被网络欺凌：**
1. ❌ 不要回应或报复
2. 📸 保存证据（带日期的截图）
3. 🚫 屏蔽欺凌者
4. 📢 向平台报告
5. 🗣️ 告诉信任的成年人
6. 📝 如果涉及同学，向学校报告

**如果您看到网络欺凌：**
1. ❌ 不要参与或分享内容
2. 💬 私下联系受害者表示支持
3. 📢 向平台报告内容
4. 🗣️ 如果严重，告诉信任的成年人
5. ✨ 在线展示积极行为

### 🎯 法则7：识别诈骗

**常见诈骗：**
🚩 "免费礼物" - 实际上是陷阱
🚩 网络钓鱼链接 - 窃取您的信息
🚩 假冒网站 - 看起来真实但不是
🚩 太好而不真实的提议
🚩 要求密码或个人信息

**保持安全：**
✅ 在点击链接之前三思
✅ 检查网址是否拼写正确
✅ 永远不要输入密码，除非您知道网站是真实的
✅ 如果看起来太好而不真实，可能就是
✅ 向成年人寻求帮助

### 🎮 法则8：游戏安全

**在游戏时：**
✅ 使用假名而不是真名
✅ 不要分享个人信息
✅ 对游戏朋友保持警惕
✅ 使用内置聊天控制
✅ 举报不当行为
✅ 设置支出限制
✅ 注意游戏时间

**警告信号：**
🚩 有人要求您离开游戏聊天
🚩 他们想知道您住在哪里
🚩 他们发送不当内容
🚩 他们提供免费物品以换取信息

## 特定平台安全提示

### Instagram
- 将账户设为私密
- 只接受您认识的人
- 关闭位置标签
- 小心故事中的内容
- 使用双因素认证

### TikTok
- 使用家庭配对功能
- 将账户设为私密
- 限制谁可以评论
- 小心二重唱和拼接
- 过滤评论

### Snapchat
- 使用幽灵模式
- 限制谁可以联系您
- 小心Snap地图
- 不要打开陌生人的Snap
- 报告不当内容

### YouTube
- 使用受限模式
- 不要分享个人信息
- 举报不当内容
- 小心评论
- 使用YouTube Kids（如果适合年龄）

### WhatsApp
- 使用隐私设置
- 不要加入陌生群组
- 验证转发的消息
- 屏蔽陌生号码
- 小心点击链接
