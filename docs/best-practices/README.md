# Digital Safety Best Practices

This comprehensive guide outlines best practices for digital safety, covering essential topics for individuals, families, and communities.

## Core Principles of Digital Safety

### 1. Privacy First
- Protect personal information
- Use privacy settings effectively
- Understand data collection and usage
- Control your digital footprint

### 2. Think Before You Click/Share/Post
- Verify sources and links
- Consider long-term consequences
- Respect others' privacy
- Maintain digital reputation

### 3. Stay Informed
- Keep up with new threats
- Update security knowledge
- Learn about new platforms
- Share information with others

### 4. Use Strong Security Practices
- Strong, unique passwords
- Multi-factor authentication
- Regular software updates
- Secure devices and networks

### 5. Maintain Digital Wellbeing
- Balance online and offline life
- Take regular breaks
- Monitor mental health
- Foster real-world connections

## Password Security

### Creating Strong Passwords

**Best Practices:**
✅ Minimum 12 characters (longer is better)
✅ Mix of uppercase and lowercase letters
✅ Include numbers and symbols
✅ Use passphrases (e.g., "BlueSky!Runs4Miles@Dawn")
✅ Unique password for each account
✅ Change passwords if compromised
✅ Use a password manager

**Avoid:**
❌ Personal information (names, birthdays)
❌ Common words or phrases
❌ Sequential numbers or letters (123456, abcdef)
❌ Reusing passwords across accounts
❌ Sharing passwords (except with parents)
❌ Writing passwords in plain sight

### Multi-Factor Authentication (MFA)

**What is MFA?**
Adding an extra layer of security beyond passwords (e.g., SMS code, authenticator app, biometrics)

**Why use MFA?**
- Even if password is stolen, account stays secure
- Alerts you to unauthorized access attempts
- Industry standard for important accounts

**Where to use MFA:**
- Email accounts
- Banking and financial services
- Social media accounts
- Cloud storage
- Work/school accounts
- Any account with sensitive information

**Types of MFA:**
1. **SMS codes**: Sent to your phone
2. **Authenticator apps**: Google Authenticator, Microsoft Authenticator
3. **Physical keys**: YubiKey, Titan Security Key
4. **Biometrics**: Fingerprint, face recognition

## Privacy Settings

### Social Media Privacy Checklist

**Profile Settings:**
- [ ] Set account to private/friends only
- [ ] Disable location services
- [ ] Turn off activity status
- [ ] Hide email and phone number
- [ ] Limit who can tag you
- [ ] Control who can see your friend list
- [ ] Disable facial recognition (where available)
- [ ] Review third-party app permissions

**Content Settings:**
- [ ] Set default post privacy to "Friends"
- [ ] Disable public search indexing
- [ ] Hide old posts from public view
- [ ] Turn off location tagging
- [ ] Limit who can see your stories
- [ ] Control who can comment on posts

**Communication Settings:**
- [ ] Control who can message you
- [ ] Filter message requests
- [ ] Block strangers
- [ ] Report suspicious accounts
- [ ] Disable read receipts (optional)

### Mobile Device Privacy

**iPhone/iOS:**
- Settings > Privacy & Security
- Review app permissions
- Limit ad tracking
- Use "Ask App Not to Track"
- Enable Find My iPhone

**Android:**
- Settings > Privacy/Security
- Review app permissions
- Limit ad personalization
- Use Google Account security checkup
- Enable Find My Device

**Both Platforms:**
- Use strong passcode/biometric lock
- Enable automatic updates
- Review installed apps regularly
- Use secure Wi-Fi only
- Enable encryption
- Regular backups

## Recognizing and Avoiding Scams

### Common Online Scams

**Phishing Emails/Messages:**
- Fake messages pretending to be from legitimate companies
- Often create urgency ("Your account will be closed!")
- Contain suspicious links or attachments
- Ask for personal information or passwords

**Red Flags:**
🚩 Spelling and grammar errors
🚩 Generic greetings ("Dear Customer")
🚩 Urgent or threatening language
🚩 Requests for sensitive information
🚩 Suspicious sender email address
🚩 Hovering over links shows different URL

**How to Verify:**
1. Don't click links in suspicious emails
2. Go directly to official website
3. Contact company through official channels
4. Check sender's email address carefully
5. Look for security indicators (https://, padlock icon)

**Social Media Scams:**
- Fake giveaways or contests
- Impersonation accounts
- Romance scams
- Investment schemes
- Job offer scams

**Online Shopping Scams:**
- Too-good-to-be-true deals
- Fake websites mimicking real stores
- Advance payment scams
- Counterfeit goods

### Protection Strategies

✅ Verify website legitimacy before purchasing
✅ Use secure payment methods (credit card, PayPal)
✅ Check seller reviews and ratings
✅ Be skeptical of unsolicited offers
✅ Research before making financial decisions
✅ Use official app stores only
✅ Keep software updated
✅ Use antivirus software
✅ Report scams to authorities

## Safe Browsing Practices

### Website Safety

**Check for Security:**
- Look for "https://" in URL (not just "http://")
- Look for padlock icon in address bar
- Verify website address is correct
- Check for trust seals (click to verify)

**Avoid:**
❌ Clicking on pop-up ads
❌ Downloading from untrusted sources
❌ Visiting pirated content sites
❌ Clicking shortened links from unknown sources
❌ Entering payment info on unsecured sites

### Safe Downloading

**Best Practices:**
✅ Download only from official sources
✅ Read permissions before installing
✅ Check reviews and ratings
✅ Use antivirus to scan downloads
✅ Keep number of apps minimal
✅ Uninstall unused apps
✅ Update apps regularly

**Warning Signs:**
🚩 App requests excessive permissions
🚩 No or very few reviews
🚩 Suspicious developer information
🚩 Offers seem too good to be true
🚩 Poor spelling/grammar in description

## Social Media Safety

### Content Sharing Guidelines

**Think T.H.I.N.K. before posting:**
- **T**rue: Is it accurate?
- **H**elpful: Does it add value?
- **I**nspiring: Is it uplifting?
- **N**ecessary: Does it need to be shared?
- **K**ind: Is it respectful?

**Never Share:**
❌ Full name, address, phone number
❌ School name and location
❌ Travel plans (in real-time)
❌ Financial information
❌ Passwords or security answers
❌ Compromising photos or videos
❌ Others' personal information without consent

**Be Cautious About:**
⚠️ Photos showing identifiable locations
⚠️ Information about daily routines
⚠️ Details that could be used for identity theft
⚠️ Content you wouldn't want your grandma to see

### Handling Negative Interactions

**If You're Being Harassed:**
1. Don't respond or retaliate
2. Document everything (screenshots)
3. Block the person
4. Report to platform
5. Tell trusted adult
6. Report to authorities if threatened

**If You Witness Harassment:**
1. Support the victim
2. Don't share or amplify the content
3. Report the behavior
4. Be an upstander, not bystander

## Device Security

### Computer Security

**Essential Protections:**
✅ Install antivirus software
✅ Enable firewall
✅ Use standard (not admin) account for daily use
✅ Encrypt hard drive
✅ Regular backups
✅ Screen lock with password
✅ Automatic updates enabled

**Regular Maintenance:**
- Update operating system
- Update all software
- Run security scans
- Clear browser cache/cookies
- Review installed programs
- Check for unusual activity

### Mobile Security

**Smartphone Protection:**
✅ Strong passcode or biometric lock
✅ Automatic lock (30-60 seconds)
✅ Two-factor authentication
✅ Encrypted backups
✅ Find My Device enabled
✅ Only apps from official stores
✅ Regular OS updates
✅ Review app permissions

**Lost/Stolen Device Plan:**
1. Enable Find My Device in advance
2. Know how to remotely lock/wipe device
3. Have backup of important data
4. Change passwords for accounts on device
5. Report to authorities
6. Notify mobile carrier

## Network Security

### Home Wi-Fi

**Secure Your Network:**
✅ Change default router password
✅ Use WPA3 or WPA2 encryption
✅ Create strong Wi-Fi password
✅ Change default network name (SSID)
✅ Enable router firewall
✅ Update router firmware
✅ Disable WPS (Wi-Fi Protected Setup)
✅ Create guest network for visitors

### Public Wi-Fi

**Risks:**
- Unencrypted connections
- Man-in-the-middle attacks
- Fake hotspots
- Data interception

**Safe Practices:**
✅ Verify network name with establishment
✅ Use VPN (Virtual Private Network)
✅ Avoid sensitive transactions (banking)
✅ Use https:// websites only
✅ Turn off automatic connection
✅ Forget network after use
✅ Use mobile data for sensitive activities

## Email Security

### Email Best Practices

**Incoming Email:**
- Be suspicious of unexpected emails
- Verify sender before clicking links
- Don't open suspicious attachments
- Check for phishing indicators
- Use spam filters

**Outgoing Email:**
- Be careful what you write (email is permanent)
- Verify recipients before sending
- Think twice before including sensitive info
- Use BCC for mass emails (privacy)
- Consider email encryption for sensitive content

**Account Security:**
- Strong, unique password
- Enable two-factor authentication
- Regular password changes
- Monitor for suspicious activity
- Don't use email for password storage

## Data Protection

### Personal Data Management

**What is Personal Data?**
- Name, address, phone number
- Email addresses
- National identification numbers
- Financial information
- Medical records
- Location data
- Biometric data
- Online identifiers (IP address, cookies)

**Singapore's PDPA (Personal Data Protection Act):**
- Organizations must protect your data
- You have right to access your data
- You can request corrections
- You can withdraw consent
- You can file complaints

**Your Responsibilities:**
✅ Read privacy policies
✅ Understand what data is collected
✅ Give consent knowingly
✅ Protect your own data
✅ Report data breaches
✅ Exercise your rights

### Cloud Storage Security

**Best Practices:**
✅ Use reputable providers
✅ Enable two-factor authentication
✅ Encrypt sensitive files before uploading
✅ Use strong passwords
✅ Limit sharing permissions
✅ Regular security reviews
✅ Understand provider's terms

**What to Store:**
- Backup of important files
- Non-sensitive documents
- Encrypted sensitive data

**What NOT to Store:**
❌ Unencrypted sensitive documents
❌ Passwords (unless in secure password manager)
❌ Financial records (unless encrypted)
❌ Confidential work information (check policies)

## Digital Wellbeing

### Healthy Screen Time

**Guidelines by Age:**
- **Under 18 months**: None (except video calls)
- **18-24 months**: Limited, high-quality content with parent
- **2-5 years**: Max 1 hour per day, co-viewing preferred
- **6-12 years**: Consistent limits set by parents
- **13+ years**: Balance with other activities, sleep, exercise

**For Everyone:**
- Set tech-free times (meals, before bed)
- Create tech-free zones (bedrooms, dining room)
- Use screen time tracking
- Take regular breaks
- Balance online and offline activities

### Recognizing Problematic Use

**Warning Signs:**
🚩 Neglecting responsibilities
🚩 Withdrawal from real-world activities
🚩 Mood changes related to device use
🚩 Sleep disruption
🚩 Physical symptoms (eye strain, headaches)
🚩 Inability to cut back
🚩 Lying about usage
🚩 Using tech to escape problems

**Getting Help:**
- Talk to trusted adult
- Consult healthcare provider
- Seek counseling if needed
- Use digital wellbeing tools
- Join support groups

## Emergency Response

### If You Encounter Online Threats

**Immediate Actions:**
1. Stop interacting
2. Do not delete (evidence)
3. Take screenshots
4. Block the person/account
5. Report to platform
6. Tell trusted adult
7. File police report if necessary
