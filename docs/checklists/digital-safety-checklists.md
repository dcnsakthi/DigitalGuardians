# Digital Safety Checklists

Quick, actionable checklists to help families maintain online safety.

---

## Quick Start Checklist for New Parents

Use this checklist when setting up devices for your child for the first time.

### Device Setup
- [ ] Create a separate user account for your child
- [ ] Enable parental controls at the OS level
- [ ] Set up screen time limits
- [ ] Configure content filtering
- [ ] Disable in-app purchases or require password
- [ ] Turn off location services for apps that don't need it
- [ ] Review and adjust privacy settings

### Account Safety
- [ ] Create strong, unique passwords
- [ ] Enable two-factor authentication where available
- [ ] Use a password manager
- [ ] Set up family accounts (Google Family Link, Apple Family Sharing, etc.)
- [ ] Register email addresses for parental notifications

### Communication
- [ ] Discuss the family's digital safety rules
- [ ] Explain why these rules exist
- [ ] Agree on consequences for breaking rules
- [ ] Establish "tech-free" times and zones
- [ ] Create an open-door policy for concerns

### Initial Education
- [ ] Watch an age-appropriate online safety video together
- [ ] Role-play scenarios (stranger messages, cyberbullying)
- [ ] Show them how to block and report
- [ ] Practice identifying suspicious links
- [ ] Review privacy settings together

## Monthly Digital Safety Checklist

Complete these tasks once a month to maintain ongoing safety.

### Week 1: Device Review
- [ ] Update all devices and apps
- [ ] Review installed apps - remove unused ones
- [ ] Check storage - ensure nothing inappropriate is saved
- [ ] Test parental controls are still working
- [ ] Review screen time reports

### Week 2: Account Audit
- [ ] Change passwords if needed
- [ ] Review active sessions on major accounts
- [ ] Check privacy settings on social media
- [ ] Verify two-factor authentication is enabled
- [ ] Review friend lists and followers

### Week 3: Content Check
- [ ] Spot-check browser history
- [ ] Review recent photos and videos
- [ ] Check downloaded files
- [ ] Look at recent social media posts
- [ ] Review messaging app contacts

### Week 4: Family Discussion
- [ ] Have a 15-minute check-in about online experiences
- [ ] Discuss any concerns or questions
- [ ] Update rules if needed based on maturity
- [ ] Review current digital citizenship
- [ ] Plan next month's focus area

## Social Media Setup Checklist

Use this when your child creates their first social media account.

### Before Creating the Account
- [ ] Research the platform and age requirements
- [ ] Understand the platform's safety features
- [ ] Read the privacy policy together
- [ ] Discuss potential risks specific to this platform
- [ ] Set clear expectations and rules

### Account Creation
- [ ] Use a username that doesn't reveal real name
- [ ] Create a strong password
- [ ] Use your email for account recovery
- [ ] Don't provide real birthdate (if allowed)
- [ ] Skip optional personal information

### Privacy Settings (Adjust all to maximum privacy)
- [ ] Set profile to private/friends only
- [ ] Disable location sharing
- [ ] Turn off "find by phone number/email"
- [ ] Disable message requests from strangers
- [ ] Turn off read receipts
- [ ] Disable activity status
- [ ] Restrict who can comment on posts
- [ ] Limit who can tag you in photos
- [ ] Disable ad personalization if possible

### Profile Information
- [ ] No full name
- [ ] No school or location
- [ ] No phone number or address
- [ ] No birthdate or age
- [ ] Use appropriate profile picture
- [ ] Write appropriate bio

### Follow-up Actions
- [ ] Parent follows/friends the account
- [ ] Set up activity notifications
- [ ] Discuss what's appropriate to post
- [ ] Create a posting approval process (for younger kids)
- [ ] Schedule monthly privacy setting reviews

## App Download Checklist

Use this before allowing your child to download any new app.

### Research Phase
- [ ] What is the app's purpose?
- [ ] What is the age rating?
- [ ] Read reviews from other parents
- [ ] Check Common Sense Media rating
- [ ] Research known safety concerns
- [ ] Understand what data the app collects
- [ ] Review the app's privacy policy

### Safety Features
- [ ] Does it have parental controls?
- [ ] Can you disable chat features?
- [ ] Can you report/block users?
- [ ] Does it have content filtering?
- [ ] Are there in-app purchases?
- [ ] Does it collect location data?

### Decision Making
- [ ] Does the benefit outweigh the risk?
- [ ] Is there a safer alternative?
- [ ] Is your child mature enough for this app?
- [ ] Can you monitor their use?
- [ ] Have you set clear rules for use?

### After Download
- [ ] Configure privacy settings together
- [ ] Set up parental controls
- [ ] Create account with supervision
- [ ] Add to your monitoring routine
- [ ] Schedule a 2-week review

## Cyberbullying Response Checklist

Use this if your child is experiencing cyberbullying.

### Immediate Actions
- [ ] Don't respond or retaliate
- [ ] Take screenshots of evidence (with dates/times)
- [ ] Save all messages
- [ ] Block the bully on all platforms
- [ ] Report to the platform
- [ ] Ensure your child knows it's not their fault

### Document Everything
- [ ] Date and time of incidents
- [ ] Platform where it occurred
- [ ] Username of bully
- [ ] Nature of harassment
- [ ] Any witnesses
- [ ] Screenshots or saved messages
- [ ] Your child's emotional state

### Reporting
- [ ] Report to the platform/app
- [ ] Notify school if bully is a classmate
- [ ] Contact other parents if appropriate
- [ ] File police report if threats are serious
- [ ] Contact platform's trust and safety team
- [ ] Keep records of all reports made

### Support Your Child
- [ ] Listen without judgment
- [ ] Validate their feelings
- [ ] Reassure them it's not their fault
- [ ] Monitor for signs of distress
- [ ] Consider professional counseling
- [ ] Maintain open communication
- [ ] Follow up regularly

### Prevention Going Forward
- [ ] Review and tighten privacy settings
- [ ] Temporarily increase monitoring
- [ ] Discuss healthy boundaries
- [ ] Build resilience strategies
- [ ] Connect with supportive peer groups
- [ ] Create an action plan for future incidents

## Gaming Safety Checklist

Use this to ensure safe gaming experiences.

### Initial Setup
- [ ] Create child account on gaming platform
- [ ] Enable parental controls
- [ ] Disable voice chat with strangers
- [ ] Turn off video chat features
- [ ] Disable or limit text chat
- [ ] Require approval for friend requests
- [ ] Set spending limits or disable purchases
- [ ] Use privacy settings to limit profile visibility

### Game Selection
- [ ] Check ESRB/age rating
- [ ] Research online interactions
- [ ] Read parent reviews
- [ ] Understand multiplayer features
- [ ] Know if it has chat functions
- [ ] Check for user-generated content
- [ ] Understand monetization (loot boxes, etc.)

### Ongoing Monitoring
- [ ] Review friends list periodically
- [ ] Check in-game purchases
- [ ] Monitor time spent gaming
- [ ] Ask about gaming experiences
- [ ] Watch gameplay occasionally
- [ ] Review messages/chat logs if possible
- [ ] Ensure gaming doesn't interfere with sleep/school

### Red Flags to Watch For
- [ ] Secretive about gaming activities
- [ ] Suddenly defensive about gaming
- [ ] Receives gifts or items from "friends"
- [ ] Wants to meet online friends in person
- [ ] Emotional after gaming sessions
- [ ] Neglecting responsibilities for gaming

## School Year Digital Safety Checklist

Complete at the start of each school year.

### Device Preparation
- [ ] Update all devices and software
- [ ] Clear out old accounts and apps
- [ ] Review and update parental controls
- [ ] Set up new school-required apps safely
- [ ] Organize digital homework space
- [ ] Review printer and device-sharing settings

### Communication
- [ ] Review family digital safety rules
- [ ] Discuss new risks for the upcoming age/grade
- [ ] Set screen time schedules around homework
- [ ] Establish homework-only device usage times
- [ ] Create tech-free study zones
- [ ] Discuss appropriate school email use

### School-Specific
- [ ] Understand school's acceptable use policy
- [ ] Know school's cyberbullying policy
- [ ] Save important school contacts
- [ ] Set up school portal accounts securely
- [ ] Understand school's social media policy
- [ ] Know who to contact for tech issues

### Social Considerations
- [ ] Discuss new social dynamics online
- [ ] Address peer pressure around apps/games
- [ ] Talk about posting school-related content
- [ ] Review appropriate communication with teachers
- [ ] Discuss digital drama prevention

## Emergency Response Checklist

Keep this handy for urgent situations.

### If Your Child Is in Immediate Danger
- [ ] Call 911
- [ ] Remove child from situation
- [ ] Document everything
- [ ] Preserve all evidence
- [ ] Contact school if relevant
- [ ] Seek legal advice if needed
- [ ] Get professional support

### If You Discover Inappropriate Contact
- [ ] Stop all communication immediately
- [ ] Do NOT confront the person online
- [ ] Do NOT delete evidence
- [ ] Take screenshots of everything
- [ ] Report to NCMEC CyberTipline (CyberTipline.org)
- [ ] Contact local law enforcement
- [ ] Report to the platform
- [ ] Seek counseling for your child

### If Personal Information Was Shared
- [ ] Assess what information was shared
- [ ] Change passwords immediately
- [ ] Enable two-factor authentication
- [ ] Monitor accounts for unusual activity
- [ ] Consider credit monitoring (if financial info shared)
- [ ] Report identity theft if necessary
- [ ] Update security questions
- [ ] Notify relevant institutions (bank, school, etc.)

### Important Contact Numbers
- Emergency: 911
- National Suicide Prevention Lifeline: 988
- Crisis Text Line: Text HOME to 741741
- NCMEC CyberTipline: 1-800-843-5678
- FBI IC3: IC3.gov
- Cyberbullying Research Center: cyberbullying.org
